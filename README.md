# NONNA PIZZAS

Sistema web para gestión y pedidos de NONNA PIZZAS.

## Funcionalidades

- Página pública para clientes
- Menú de pizzas
- Carrito y pedidos
- Panel de administración
- Gestión de productos
- Gestión de horarios y estado del negocio
- Soporte para pizzas especiales

## Tecnologías

- Node.js
- Express
- HTML
- CSS
- JavaScript

## Ejecución local

```bash
npm install
node server.js
